# מעבדת הנקניקיות — CHARCUTIER OS

אפליקציית PWA בעברית לחישוב והכנת נקניקיות אמולסיה. האפיון המלא: `SPEC.md`.

## פקודות
```bash
npm install
npm test             # בדיקות המנוע
npm run dev          # פיתוח מקומי
npm run build        # PWA להתקנה → dist/
npm run build:single # קובץ HTML יחיד → dist-single/index.html
```

## התקנה באנדרואיד (PWA מלא, עובד גם בלי אינטרנט)
1. היכנס ל-https://app.netlify.com/drop (חינם, צריך חשבון).
2. גרור לשם את התיקייה `dist` אחרי `npm run build`.
3. פתח את הכתובת שקיבלת ב-Chrome בטלפון.
4. תפריט ⋮ ← "הוספה למסך הבית" / "התקנת אפליקציה".

## מבנה
- `src/engine` — מנוע החישובים, בלי תלות בממשק. כל הנוסחאות והבדיקות.
- `src/ui` — מסכים ורכיבים.
- `src/store.ts` — מצב האפליקציה, נשמר אוטומטית (שורד רענון).
- `public` — manifest, service worker, אייקונים.
